# Kripa

Author: Kedar Gadge. License: SIL Open Font License 1.1 (see OFL.txt).

Web variable font: https://github.com/google/fonts/tree/main/ofl/kripa

The font is served locally through /fonts/kripa/Kripa-Variable.ttf.
Typography is configured in app/forms.css for both body text and headings.

Mobile static weights are bundled in app_management_student/assets/fonts/kripa
from https://github.com/kedar9/kripa/tree/main/fonts/ttf and loaded by the root
layout. Use src/components/Typography for new Text and TextInput components
to preserve Kripa and the requested font weight across platforms.
